# Campus Hub

長崎大学の学務ポータルのリデザイン案。学生・教員・事務の3役割を切り替えて体験できる、Vite + React 18 / JavaScriptのプロトタイプです。バックエンドや実際の認証はありません。

> 以前このリポジトリのmainにあった試作（`NUWeb Redesign.html` など）は、ブランチ `archive/nuweb-prototype` にそのまま保管しています。

## 起動

```sh
npm install
npm run dev
```

表示されたURL（通常 `http://localhost:5173`）を開きます。

```sh
npm run build
npm run preview
node scripts/check.mjs
```

`dist/` が配布物です。HashRouterと `base: './'` を使用しているため、GitHub Pagesのサブディレクトリにも対応します。GitHub Pagesでの公開（`dist/` の扱い）は未決定です。

## 操作例

- 履修登録：開講科目の「＋追加」かドラッグで仮登録します。違うコマに落としても科目の本来の曜日・時限に入ります。☆の科目は一覧上部に固定されます。「会計学」と「経済数学A」は火4で重複します。13科目以上（26単位）を追加すると学期上限24単位の警告を表示します。警告は登録を禁止しません。
- 卒業要件：取得済み64単位に仮登録の取得見込みを加算します。実際の取得済み単位が増えたことを意味しません。区分別の数字・進捗・残り単位も変わります。
- 確定：確認モーダルで一覧・合計・警告を確認し「この内容で登録する」。時間割がこの内容に置き換わります。時間割の専用履修登録ボタンは確定済み科目を仮登録へ引き継ぎます。一括削除は仮登録だけを消し、再確定まで確定済み時間割を保持します。
- CSV：時間割から書き出したCSVを取り込めます。形式は `id,科目名,曜日,時限,教員,教室,単位,区分,種別`。新規科目も追加可能。ID重複・不正な曜日/時限/単位はエラーにして全体を取り込みません。引用符・カンマ・改行を含むセルに対応しています。
- カレンダー：ICSをダウンロードしGoogleカレンダーの設定 → インポートから取り込みます。2026年10月5日の週を起点とする毎週の授業予定を出力します（日本時間、2027年2月1日まで）。祝日・休講はモックに含まれません。
- 成績CSV：教員画面でテンプレートを取得し `学籍番号,点数` のCSVを取り込みます。科目ごとに保存します。未知の学籍番号・0〜100以外の点数は拒否します。
- 申請連携：学生で申請 → アバターから事務へ切替 → 各種申請で「承認」 → 学生へ切替 → 申請状況が「完了」になります。
- お知らせ連携：教員で担当科目に配信 → 学生へ切替 → お知らせで閲覧できます。全学・経済学部・1年と、履修している科目宛てのお知らせがデモ学生の対象です。
- サイドバーは64pxからホバー・キーボードフォーカスで240pxに展開し、本文を動かさず重なります。768px未満は下部タブバー。小さな画面の時間割・表はカード内で横スクロールできます。

## データと制約

初期モックは `src/data/mock.js`。状態はReact stateと `ch-` から始まるlocalStorageキーに保存します。同一タブの役割切替で即反映、再読み込みでも保持します。別ブラウザとの同期やサーバー保存はありません。データを初期化する場合はブラウザのサイトデータからこのアプリのlocalStorageを削除してください。

日付は2026年10月8日で固定。PLANの「水曜日」は実際の暦と異なるため、木曜日で統一し、授業時限はPLAN指定の8:50〜19:20を使用しています。成績・統計・受講者はモックです。デモ学生「小宮路 健心」は元のUI画像に合わせた名前で、表示される成績・出欠・GPAはすべて架空です。卒業要件124単位・区分別単位・学期上限24単位・時限（8:50〜19:20）・在学生数8,421人・履修登録率96.2%・人気倍率・履修登録期限などの数字は**長崎大学の実資料で裏を取っていない仮の値**です。Noto Sans JPはGoogle Fontsから読み込み、接続不可時はOSのsans-serifで表示します。アイコンとグラフは自前SVGです。

共有リンク・画像出力はPLANで認められたデモです。実際の画像ファイル生成や他人への時間割共有は行いません。印刷はブラウザの印刷ダイアログからPDF保存できます。ICS連携はファイルインポート方式で、Googleへの自動同期ではありません。
