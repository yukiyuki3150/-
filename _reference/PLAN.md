# Campus Hub プロトタイプ 実装計画（孔明 → Codex）

## 目的
長崎大学の学務ポータル（NU-Web）のリデザイン案「Campus Hub」の、**動くプロトタイプ**を作る。
学生・教員・事務の三者が同じデータ基盤を使い、ログインした役割で画面が変わる。
バックエンドなし。データは全部フロント側のモック（`src/data/`）、状態は React state + localStorage。

参照: `_reference/1.webp`〜`5.webp`（UI画像）と `_reference/meeting.txt`（ミーティング文字起こし。リポジトリには含めずローカルのみ）。
画像は見た目の手本。色・余白・角丸・カードの雰囲気をできるだけ寄せる（濃紺サイドバー #0f2350 前後、アクセント青 #1a6ff0 前後、白カード、薄いグレー背景、Noto Sans JP）。

## 技術
- Vite + React 18 + JavaScript（TypeScript なし）。ルーティングは react-router-dom（HashRouter：GitHub Pages で動くように）。
- 追加ライブラリは最小限。アイコンは lucide-react 可。ドラッグ&ドロップは HTML5 DnD を自前で（ライブラリ不要）。グラフは自前SVG。
- `vite.config.js` に `base: './'`。`npm run build` が通ること。
- フォルダ: このファイルの親の親（リポジトリ直下）がプロジェクトルート（2026-10-08 に `campus-hub/` から直下へ移動）。`_reference/` はそのまま残す（.gitignore しない）。
- README.md（日本語）: 起動方法、画面一覧、ミーティングで決まったこと→どこに反映したか の対応表。

## 画面構成

### 0. ログイン画面 `/`
- 「学生としてログイン」「教員としてログイン」「事務としてログイン」の3ボタン（画像3の構図）。認証は無し、押すと役割を localStorage に保存して各ホームへ。
- どの画面でもヘッダー右のアバターから役割切替・ログアウトできる。

### 共通レイアウト：ホバーで広がるサイドバー（画像5 ①②）
- 通常はアイコンだけの細いサイドバー（幅 ~64px、濃紺）。
- マウスを乗せると幅 ~240px に**スライドして広がり**、ラベル付きメニューが出る（コンテンツの上に重なる overlay。本文はずれない）。transition 200ms。
- 下部にユーザーのアバター＋名前（広がった時だけ名前表示）。
- 上部ヘッダー：ロゴ「Campus Hub」、全体検索バー（科目・お知らせ）、通知ベル（未読数バッジ）、アバター。
- モバイル幅（<768px）ではサイドバーは下部タブバーに変わる（スマホ対応はミーティングで要望あり）。

### 学生（主役。一番作り込む）
メニュー：ホーム／時間割／履修登録／マイタスク／成績・履修状況／お知らせ／各種申請

1. **ホーム**（画像4の②カード・モダンタイプが土台、画像5③）
   - 「おかえりなさい、小宮路さん👋」＋キャンパス風ヘッダー画像（CSSグラデーションで代用可）＋日付。
   - 4枚のカード：今週の授業 N件／課題 N件（提出期限あり）／お知らせ N件（未読）／各種申請。押すと各ページへ。
   - **今日の予定**（時刻・科目・教室のリスト）をホームに出す（ミーティングで決定）。

2. **時間割**（画像1・画像4④がベース、ミーティングで整理した版）
   - **一番上**にシラバス検索：キーワード入力＋検索ボタン、絞り込み（開講年度／学部・学科／曜日／開講時限）、人気のキーワードチップ。シラバス検索はこのページ上部の1か所だけ（他の重複は置かない、と決まった）。検索結果は時間割の下にリスト表示 or モーダル。
   - 週表示の時間割グリッド（月〜金 × 1〜6限、長崎大の時限：1限 8:50-10:20／2限 10:30-12:00／3限 12:50-14:20／4限 14:30-16:00／5限 16:10-17:40／6限 17:50-19:20 で統一）。週/月切替、前週・次週・今週。今日の列を薄くハイライト。コマをクリックで科目詳細（教員・教室・シラバス概要）のポップオーバー。
   - 右側に **クイックアクション**（ミーティングで「優秀」と評価、残す）：
     - 個人カレンダー連携（Googleカレンダー）→ 実際に .ics ファイルを生成してダウンロード
     - 時間割をダウンロード → 印刷用ビュー（window.print）
     - 時間割の共有（友達に）→ 共有リンク風のモーダル＋画像出力ボタン（ダミーでよい）
     - CSV 取り込み／書き出し（筑波の非公式アプリ「AKICO」のようにCSVで一括登録できる仕組みを付けるべき、と決まった）→ 書き出しは実際にCSVを生成、取り込みはファイル選択→パースして登録科目に反映
   - **「＋ 履修登録」専用ボタン**を目立つ位置に（履修登録ページへ）。
   - 小さいミニカレンダーは不要（と決まった）。登録科目一覧は右側に残してよい。

3. **履修登録**（画像2がベース。ミーティングでほぼ承認済み）
   - 上部：タイトル＋年度、ステップ表示 ①科目を選ぶ ②時間割に配置 ③登録内容を確認、右上「登録内容を確認 →」ボタン。
   - **卒業要件の達成状況**：取得単位 64/124、進捗バー、達成率%、「あと60単位」。区分別カード（共通教育 22/28、専門教育 30/78、自由選択 12/18 …）。今回仮登録した分を加味して数字が**リアルタイムに変わる**こと。
   - 中段は**左右半々**：左＝時間割（仮登録中）、右＝開講科目一覧（ミーティングで「半々・横並び」と決定）。
   - 開講科目一覧：学部・曜日・時限の絞り込み、検索、分野チップ。各行：☆お気に入り、科目名、人気バッジ（倍率／人気）、担当教員、曜日・時限、単位、教室、「＋追加」。
     - ☆を付けた科目は**一覧の上に固定**される。
     - 行を**時間割の空きコマにドラッグ&ドロップ**すると仮登録（AKICO風）。ドラッグ中、置けるコマ（その科目の曜日時限）を点線ハイライト。違う場所に落としたら本来のコマに入る or 拒否（どちらか分かりやすい方）。「＋追加」でも同じ結果。
     - 仮登録済み科目は時間割上に表示、外すボタンはカードにホバーした時だけ出る（誤タップ防止の議論あり）。外す前に確認。
   - 下部バー：登録中の単位数、区分別内訳（必修／選択必修／選択）、**同一時限の重複警告**（件数＋詳細）。**学期の上限単位を超えたら警告**（「オーバーしますよ」程度。禁止はしない）。
   - 「登録内容を確認」→ 確認モーダル（一覧・合計単位・警告）→「この内容で登録する」で確定。確定後は時間割ページにも反映。
   - 「カレンダーから一括削除」ボタン。

4. **マイタスク**（画像4⑤）：タブ（すべて／課題／授業／申請／お知らせ、件数バッジ）、セクション「期限が近い」「今日の予定」「今後の予定」の折りたたみ、チェックで完了（取り消し線）。

5. **成績・履修状況**（画像4⑥・画像5⑥）：今学期の履修状況ドーナツ（8/12 履修中…）、学期別の成績バー、科目ごとの成績表。
   - **GPA は初期状態で隠す**（「見せるのは強引すぎる」との意見）。「GPAを表示」トグルで出せる。

6. **お知らせ**：一覧＋未読/既読。**各種申請**：申請フォームのモック（証明書発行・欠席届など）と申請状況（受付中/処理中/完了）。学生が出した申請は事務側の一覧にも出る（同じ localStorage を共有して三者連携らしさを見せる）。

### 教員（画像3中央）
メニュー：ホーム／担当科目／学生一覧／成績入力／連絡・お知らせ／設定
- 担当科目ページ：科目切替（ミクロ経済学A など）、タブ「受講者一覧／成績入力／出欠管理／お知らせ」。
- 受講者一覧：学籍番号・氏名・出欠（○△×）・課題提出・成績（中間）、検索・絞り込み。
- 成績入力：表で点数入力→自動で評語（S/A/B/C/F）、**一括入力（CSV取り込み）**（ミーティング「成績を一括管理したい」）。
- お知らせ配信：その科目の受講生に送る→学生側のお知らせに反映される。

### 事務（画像3右）
メニュー：ホーム（ダッシュボード）／学生管理／履修・科目管理／各種申請／お知らせ配信／統計・分析／設定
- ダッシュボード：KPI（在学生数 8,421人、履修登録率 96.2%、**申請対応 32件**＝「今日やる仕事が分かる」）、重要なお知らせ、履修登録状況ドーナツ、学年別在学生数バー。
- 各種申請：学生からの申請一覧、承認/差し戻しでステータスが変わり、学生側にも反映。
- お知らせ配信：全学/学部/学年を指定して配信。

5. 学生の申請→事務で承認→学生側ステータス更新、教員のお知らせ配信→学生のお知らせに出る。
